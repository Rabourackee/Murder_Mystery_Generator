# 本格诡计构筑所 · Honkaku Trick Atelier

把推理史上的本格诡计拆成零件，按编号可复现地排列组合，再加入新本格与非本格的“风味”，生成一份完整的案件卷宗：登场人物表、现场见取图、正文、证物清单、致读者的挑战书、（封缄的）解答篇，以及诺克斯十诫 / 范·达因二十则的戒律审查。

纯静态页面，无需构建。直接用浏览器打开 `index.html` 即可。

## 用法

- **火漆印「构筑事件」**：换一个新的案件编号，重新生成。
- **构筑要素**：舞台、侦探、核心诡计、辅助诡计、动机可以手动指定，或点 🔒 锁定本次的结果，再按火漆印时它们保持不变。
- **诡计抽屉**：选择哪些诡计类别参与随机。
- **风味药柜**：手动加入风味（实心红点），或让系统随机追加（虚线框）。
- **严守戒律**：排除会触犯诺克斯十诫的零件（超自然、侦探即凶手、叙述者即凶手、双胞胎、未知毒物……）。
- **卷宗里**：点证物卡可以标记“可疑”；在挑战书里指认凶手，再拆开火漆看解答。
- **分享**：配置与编号都编码在网址的 `#c=` 里，复制链接即可让别人看到同一个案件。

## 添加新的诡计

在任一 `js/data/tricks-*.js` 里追加一个对象即可，字段说明见 `tricks-impossible.js` 文件开头的注释。模板中可用的占位符：

`{V}` 被害者 · `{C}` 凶手 · `{D}` 侦探 · `{W}` 助手 · `{S1}` `{S2}` 其他嫌疑人 · `{P}` 舞台 · `{R}` 现场 · `{R2}` 另一房间 · `{WP}` 凶器 · `{T1}` 表面时间 · `{T2}` 真实时间（较早）· `{X}` 舞台道具 · `{V2}` 第二被害者 · `{N}` 年数 · `{PAST}` 往事 · `{GROUND}` 地面

如果新诡计的 `setup` 描写的是“发现尸体”的场面，请把它的 id 加进 `generator.js` 的 `BODY_TRICKS`，避免与另一个同类诡计在开场里互相矛盾。若决定性破绽 `tell` 会直接说出结论，请另写一句中性的 `obs` 放进证物清单。

## 多语言（中文 / English）

右上角切换语言。中文数据（`js/data/`）是结构的唯一来源：id、评分、标签、约束都只写在那里。英文在 `js/i18n/en-*.js` 里只提供文本覆盖层：有 id 的按 id 覆盖，没有 id 的列表按下标对齐，**长度必须一致**。所有随机决定只依赖结构，所以同一编号在两种语言下是同一个案件，切换语言就是翻译当前案件。

- 界面与生成器用到的句子在 `js/i18n/strings-zh.js` / `strings-en.js`，键一一对应。
- 英文模板可用人称代词占位符：`{Vhe}` `{Vhim}` `{Vhis}`，C / D / W / S1 / S2 / V2 同理。
- 英文地名写成 `[首次出现的全称, 之后的简称]`。
- 新增或修改中文零件后，在浏览器控制台留意 `[i18n] en overlay issues` 警告，它会列出缺失的翻译和长度不一致的数组。

## 关于剧透

图鉴与构筑笔记中列出了各个诡计的代表作品。作品名默认模糊处理，悬停或点击才会显示。
